# Learning Path

Self-directed learning has focused on the practical engineering side of
generative AI rather than pure theory.

## Areas Covered

- RAG system design — chunking, retrieval, hybrid search, evaluation.
- MLOps practices for ML/LLM systems — see [[MLOps-Fundamentals]].
- Agentic AI patterns — tool use, planning loops — see
  [[Agentic-AI-Concepts]].

## Approach

Prefer building real, shippable projects (like [[DocuMind-Project]] and
[[Obsidian-RAG-Assistant-Project]]) over isolated tutorials, since a working
system surfaces problems (latency, cost, edge cases in real documents) that
tutorials rarely cover.
